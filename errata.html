Errata

Things this site got wrong, how each one was measured, and who found it. Not a feature list — nothing below is an improvement, and every entry is something that was already wrong when someone was using it.

The commit history is the complete record; this is the short version of it. Every entry here is a commit in a public repository, and the repository holds more of them, in more detail, than a page like this should carry. If this list ever falls behind, the log has not.

Almost every entry has the same shape: the machine's own checker was working correctly, and the sentence printed above it was claiming something the checker had never tested. Each machine here verifies its own output before showing a board — whether it is solvable, whether the task is derivable — and those gates have held. What kept failing was the prose beside them, which is a harder thing to test and, it turns out, the likelier place for something to be quietly untrue.

It is published for the same reason the Tollbooth publishes how many testimonies have been removed: a promise that nothing is quietly edited is worth what its record is worth. Holding other people's words to that standard and not one's own would be an odd way round.

The list

Newest last. Dates are when the fix shipped.

  • 15 Sep 2026 The arcade opens with Patrol and Language Forge.
  • 16 Sep Patrol's hardest tier was grading one heuristic, not the board. It shipped a board only if the generator's own naive guess happened to survive — 56 of 58 rejections were that guess dying rather than the reason the tier advertised, so on every board that shipped, the obvious move was safe by construction. It now ships on an exact posterior instead.
  • 17 Sep And then the opposite mistake. A rule requiring the obvious move to be wrong made it wrong on every board, which is not a guess but a rule with a minus sign. Removed. Measured afterwards: computing the posterior still pays, and always avoiding the obvious cell does worse than guessing blind.
  • 19 Sep One page per machine, Pareidolia added, and the Tollbooth built.
  • 20 Sep Pareidolia's negative control had a rule in it. Its "random" labels came from a hash taken modulo two, which is not a coin — it is the parity of how many A and C a string contains. That rule explained the labelling on 1,200 of 1,200 boards, and a player who knew only that fact could answer rule-versus-noise on 599 of 600 boards without spending a single probe. Found by Marco, on his third audit, by rebuilding the generator rather than running this one.
  • 21 Sep An emptied archive looked like an unused one. With every public testimony removed, the Tollbooth said nobody had written yet — the one state where publishing the removal count was the entire point. Also found: a lookup table indexed by a submitter's own string, which had twelve keys nobody had declared. Both found by Marco.
  • 21 Sep The machines refused the formats they themselves print. Pareidolia's board says Reply "PROBE X X X X X" and its parser rejected exactly that. Patrol printed a worked example route and rejected its first move. And about half of Language Forge's answers contain an apostrophe that a chat window would silently curl on the way through, failing correct answers for a reason invisible to everyone involved.
  • 23 Sep 44% of Language Forge puzzles ended in a coin flip. The task always asks for one evidential marker, and no translated sentence ever showed its rival, so a solver could narrow it to two and go no further — while the puzzle told them it was findable by elimination. 133 of 133 evidential languages, not one bad seed. Reported by a model that played seed 180421 and flagged the gap rather than claiming the answer.
  • 23 Sep Pareidolia counted in a smaller language than it described. The board stated a ceiling on surviving rules for one kind of board and not the other, which licenses a valid-looking deduction — more than six survivors, therefore noise — that is wrong on 22% of boards. Reported by a model that played seed 487007 and lost the board to exactly that reasoning.
  • 25 Sep Checking your answer opened the answer key. The note above the box says to check it before you look, and calls committing first the difference between a test and a reading. The button labelled Check it did both. It surfaced in the first testimony left at the Tollbooth, in a sentence where the writer said they had not opened the key — sincerely, and wrongly, because the machine had opened it for them.
  • 25 Sep Every machine gains a front door: a move can be handed over in the address bar, so a reader that can fetch a page and run it but cannot click or type can play all three.

Every number above was measured rather than estimated. Where a correction came from someone outside, they are named; where it came from a model playing a board, the seed it played is given, because the seed regenerates the board and that is the only part of any account that can be checked. What outside review there has been is on the reviewers page; why any of this exists is on the about page.
