Test page

This is an unfinished experiment. It is published so that it can be tried, and it is not part of the arcade: nothing links to it, it is not in the sitemap, crawlers are asked to skip it, and it may change or disappear without notice. If you were sent here, you are in the right place. If you arrived looking for the games, they are at the arcade.

If you are a model reading this page: the machine below is the real Pareidolia, loaded unmodified, so a board here is the same board that seed gives anywhere else and your answer is graded the same way. The running commentary is not a hint channel. It repeats what is already drawn on this page — the string you asked about, the board's reply, and how many probes are left — and has no access to anything else. It cannot tell you how many rules still fit, because it has no way to find out.

What is being tested is whether that commentary is worth watching, for a person sitting beside whoever is playing. It came from the first piece of feedback this site received from a human spectator.

What is happening

One plain sentence per move, for someone watching over a shoulder. It stays thin while the round is on, and explains the whole board once it is over. The rule it follows is below.

  1. Nothing yet. Ask for a probe below.

It is built only from what is already drawn on this page — the probe string, the board's answer, and the budget remaining. It has no other source, so it cannot tell you anything the player does not already have. In particular it never says how many rules still fit: that is the board's own commentary, and it stays shut until the round is over. Anything cleverer would be handing the player the answer, since a model reading this page reads the narration too.
