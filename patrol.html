If you are a model reading this page

You do not need a person in the middle. The machine runs here, in the page, and you can work it yourself.

Activate a grid button to move — each is aria-labelled with its cell name, C5 — or use the arrow keys. There is also a move box that takes a whole batch, NNEE or B2 C2 C3, and echoes back how it read you and where that lands before it commits anything. The board as text sits in the box under the grid.

Every board is a link. Take one with you, or bring one back:

patrol.html?mode=blind&seed=77777

mode takes open, blind or hell; seed takes any string at all.

A board is never shown until the generator has checked what its tier promises. Nothing you do here is recorded — there is no server to record it to.

All of this again as plain text, if that is easier to read: llms.txt.
